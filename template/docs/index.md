# Welcome

This is the starter page for your Docs site. Replace it with an overview of your project, then add Markdown or MDX guides under `docs/`.

The Docs navigation is generated from your folders and page frontmatter. Add `docs/agents/` to publish agent guidance as a top-level **Agents** section. It is included by default; set `terraDocs.includeAgents` to `false` in `package.json` to hide it for this Docs instance.
